# podman-py Maintainers

This file uses the same format and **Project Roles** names as repositories in
[Podman Container Tools](https://github.com/podman-container-tools). Those role
definitions are described in [GOVERNANCE.md](https://github.com/podman-container-tools/community/blob/main/GOVERNANCE.md).

podman-py currently lives in the `containers` GitHub organization and is **not**
yet a formal member of the Podman Container Tools CNCF project. Until the
repository moves, org-wide Core Maintainers and Community Managers listed in the
[community MAINTAINERS.md](https://github.com/podman-container-tools/community/blob/main/MAINTAINERS.md)
do not have direct authority over this repository.

This file lists only podman-py's Maintainers and Reviewers.
