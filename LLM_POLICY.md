# podman-py LLM (AI) Development Policy

Please read the [Podman Container Tools LLM (AI) Development Policy](https://github.com/podman-container-tools/community/blob/main/LLM_POLICY.md).

As described in [CONTRIBUTING.md](CONTRIBUTING.md), podman-py uses this policy for
consistency with sibling projects while it remains in the `containers` GitHub
organization. Org-wide Core Maintainers do not have direct authority over this
repository until it moves to the Podman Container Tools project.
