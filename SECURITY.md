## Security and Disclosure Information Policy for the podman-py Project

The podman-py project uses the same disclosure practices described in the
[Security and Disclosure Information Policy](https://github.com/podman-container-tools/community/blob/main/SECURITY.md)
maintained for Podman Container Tools projects.

podman-py is hosted in the `containers` GitHub organization and is not yet a
formal member of the [Podman Container Tools](https://github.com/podman-container-tools)
CNCF project. Until the repository moves, that policy is followed for
consistency with sibling projects; org-wide Core Maintainers do not have direct
authority over this repository until then.
