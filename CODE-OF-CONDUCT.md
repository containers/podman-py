## The podman-py Project Community Code of Conduct

The podman-py project follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

podman-py is hosted in the `containers` GitHub organization and is not yet a
formal member of the [Podman Container Tools](https://github.com/podman-container-tools)
CNCF project. Until the repository moves, we align with sibling projects where
practical; org-wide Core Maintainers do not have direct authority over this
repository until then.
